# 윈도우에서 쓰는 법 — 처음부터 끝까지

컴퓨터를 잘 몰라도 따라올 수 있게, 빠짐없이 적었습니다.
**검은 창에 명령어를 칠 일은 없습니다.** 파일을 더블클릭하면 메뉴가 나옵니다.

전체 흐름은 이렇습니다.

```
①  ZIP 압축 풀기
②  시작하기.bat 더블클릭      (파이썬은 알아서 설치됩니다)
③  메뉴에서 1번 → 3번 누르기
④  나온 probe결과.txt 를 Claude 에게 보내기
```

사장님이 하실 일은 **압축 풀고 더블클릭, 번호 누르기**가 전부입니다.

---

## ① 파일 받기

Claude가 보낸 **`쿠팡수집도구.zip`** 을 내려받습니다.

1. ZIP 파일에서 **오른쪽 클릭 → 압축 풀기**
2. 풀린 `쿠팡수집` 폴더를 **바탕화면**으로 옮깁니다 (찾기 쉽게)

## ② 파이썬 — 신경 쓰지 않으셔도 됩니다

프로그램이 알아서 확인하고, 없으면 자동으로 설치합니다.

설치 직후에는 **"이 창을 닫고 다시 더블클릭해 주세요"** 라는 안내가 나옵니다.
윈도우가 방금 깐 프로그램을 바로 알아보지 못해서 그런 것이니, 그대로 하시면 됩니다.
한 번만 겪습니다.

> 자동 설치가 안 되는 구형 윈도우라면 직접 설치하라는 안내가 뜹니다.
> 그때는 python.org/downloads 에서 받아 설치하되,
> **설치 화면 맨 아래 `Add python.exe to PATH` 네모칸을 꼭 체크**하세요.

## ③ 실행하기

`쿠팡수집` 폴더 안의 **`시작하기.bat`** 을 **더블클릭**합니다. 그게 전부입니다.

검은 창이 뜨고 이런 메뉴가 나옵니다.

```
============================================================
  무엇을 할까요?  번호를 누르고 Enter
============================================================

  1. 점검      쿠팡 접속 없이, 저장 기능이 되는지만 확인
  2. 로그인    브라우저를 열어 쿠팡에 직접 로그인 (한 번만)
  3. 시험      상품 1개로 시험 <- 먼저 이것부터 하세요
  4. 수집      실제 수집 (5개만)
  5. 수집      실제 수집 (남은 것 전부)
  6. 진행확인  어디까지 받았는지 보기
  7. 주소저장  받아온 상품 주소를 자료에 채우기

  0. 끝내기

번호:
```

> **처음 실행하면 "playwright 를 설치합니다" 가 나오고 몇 분 걸립니다.**
> 브라우저를 내려받는 과정입니다. 한 번만 하면 다음부터는 바로 메뉴가 뜹니다.
> 그냥 기다리세요.

---

## ④ 눌러야 할 순서

### 먼저 **`1`** 을 누릅니다 — 점검

쿠팡에 접속하지 않고, 이 프로그램이 **화면을 저장하는 기능 자체**가 되는지만 봅니다.

```
스크롤 높이 13200px / PDF 성공 / 이미지 5장
```

이렇게 나오면 정상입니다. 아무 문제 없습니다.

왜 이걸 먼저 하냐면, 나중에 잘 안 될 때 **"쿠팡이 막은 건지, 프로그램이 고장난 건지"**
를 가르기 위해서입니다. 점검이 통과했다면 프로그램은 멀쩡한 겁니다.

### 그다음 **`3`** 을 누릅니다 — 시험 ⭐ 가장 중요

제품명을 물어봅니다. **그냥 Enter** 를 누르면 기본 제품으로 합니다.

브라우저 창이 저절로 뜨고, 검색하고, 상품을 열고, 스크롤을 내립니다.
**건드리지 말고 지켜보세요.** 1~2분 걸립니다.

끝나면 검은 창에 결과가 쭉 나오고, 같은 내용이 **`probe결과.txt`** 파일로도 저장됩니다.

> ### 📨 이 `probe결과.txt` 를 저에게 보내주세요
>
> `local_capture` 폴더 안에 생깁니다. 그 파일을 채팅에 첨부하시면 됩니다.
>
> 쿠팡 화면에서 '더보기' 버튼이 정확히 어떤 글자인지 제가 볼 수가 없어서
> (제 쪽에서는 쿠팡 접속이 막혀 있습니다), 그 파일이 있어야 맞출 수 있습니다.
> 파일 안에 **페이지에 실제로 보이는 버튼 글자들**이 들어 있습니다.

### 결과가 이렇게 나오면

| 화면에 나온 것 | 뜻 | 할 일 |
|---|---|---|
| `PDF 저장: probe.pdf` | **성공** | 4번으로 진행 |
| `접근이 차단되었습니다` | 쿠팡이 막음 | 2번(로그인) 먼저 하고 다시 3번 |
| `더보기 버튼을 찾지 못함` | 버튼 글자가 다름 | `probe결과.txt` 를 보내주세요 |
| `상품을 찾지 못했습니다` | 검색 결과 없음 | 제품명을 바꿔서 다시 |

### 잘 되면 **`4`** — 5개만 수집

바로 150개를 돌리지 말고 5개만 먼저 받아보세요. 3~5분 걸립니다.
`captures` 폴더에 PDF가 생기면 열어서 **내용이 제대로 담겼는지** 확인하세요.

### 확인됐으면 **`5`** — 전체 수집

150개 전부입니다. **1시간 20분** 정도 걸립니다. 상품 하나당 20~40초씩 쉬면서
사람이 보는 속도로 움직이기 때문입니다.

틀어놓고 다른 일 하셔도 됩니다. **중간에 창을 꺼도 괜찮습니다** —
다시 5번을 누르면 받다 만 곳부터 이어서 받습니다.

---

## ⑤ 다 받은 뒤

### `6` 진행확인
어디까지 받았는지, 혹시 엉뚱한 상품을 받은 건 없는지 보여줍니다.

### `7` 주소저장
받아오면서 알아낸 **실제 상품 주소 150개**를 자료에 채워 넣습니다.
지금까지 이 칸이 비어 있었는데, 한 번 채우면 다음부터는 검색 단계가 아예 사라집니다.

### PDF 보내기
`local_capture\captures` 폴더에 PDF가 쌓입니다. 그 폴더를 압축해서 저에게 보내주시면
USP 분석을 진행하겠습니다.

## 막혔을 때

| 증상 | 원인 | 해결 |
|---|---|---|
| 더블클릭하니 창이 **깜빡하고 사라짐** | 파이썬 없음 | ①번 다시. `Add python.exe to PATH` 체크했는지 확인 |
| `파이썬이 설치되어 있지 않습니다` | PATH 체크 누락 | 파이썬을 지우고 ①번부터 다시 (체크박스 꼭) |
| `Executable doesn't exist` | 브라우저 설치 안 됨 | 창을 닫고 다시 더블클릭 (자동 설치됨) |
| 브라우저가 떴는데 **아무것도 안 함** | 쿠팡이 느림 | 1~2분 더 기다려 보세요 |
| `접근이 차단` | 쿠팡이 막음 | `2` 로그인 후 재시도. 그래도 안 되면 알려주세요 |
| 한글이 **깨져 보임** | 글꼴 문제 | 검은 창 제목 오른쪽 클릭 → 속성 → 글꼴 → `굴림체` |

**어떤 경우든 검은 창에 나온 글자를 그대로 복사해서 보내주시면 됩니다.**
복사는 창 안에서 드래그 → 오른쪽 클릭입니다.

## 안 해도 되는 것

- 명령어를 외울 필요 없습니다 (메뉴에서 번호만 누름)
- 코드를 고칠 필요 없습니다
- 검은 창에 직접 타이핑할 일 없습니다 (번호와 Enter만)
- 쿠팡 아이디를 저에게 알려줄 필요 없습니다 (로그인은 사장님 PC 안에서만 이뤄지고,
  그 기록은 `.browser_profile` 폴더에 사장님 컴퓨터에만 남습니다)
