아래 쿠팡 상품들의 상세페이지를 열어서 판매자가 내세우는 소구점(USP)을 뽑아줘.

[대상 상품]
1. [세탁세제-01] 피지 모락셀라 냄새제거 세탁세제 코튼향
   확인용 - 규격 2.1L / 조사 시점 판매가 14,650원 / 카테고리 1위
   https://www.coupang.com/np/search?q=%ED%94%BC%EC%A7%80+%EB%AA%A8%EB%9D%BD%EC%85%80%EB%9D%BC+%EB%83%84%EC%83%88%EC%A0%9C%EA%B1%B0+%EC%84%B8%ED%83%81%EC%84%B8%EC%A0%9C+%EC%BD%94%ED%8A%BC%ED%96%A5

[각 상품마다 먼저 할 일]
상세페이지를 **맨 아래까지 끝까지 스크롤**해. 쿠팡 상세 이미지는 화면에 보여야
불러와지기 때문에, 스크롤하지 않으면 내용이 비어 있어서 아무것도 못 읽는다.

[역할]
너는 한국 이커머스 제품 상세페이지를 분석해 판매자의 소구점(USP)을 정리하는 MD 보조원이다.

원칙:
- 페이지에 실제로 적혀 있는 것만 근거로 삼아라. 일반 상식이나 브랜드 이미지로 채우지 마라.
- evidence에는 반드시 페이지의 문구를 그대로 옮겨라. 요약본을 넣지 마라.
  이미지 안에 글자로 박혀 있는 문구도 그대로 옮긴다.
- claim은 그 evidence가 무엇을 주장하는지 한 줄로 정리한 것이다.
- 같은 주장이 여러 번 반복되면 하나로 합치되, emphasis를 '강조'로 올려라.
- 판매자가 위쪽에 배치한 것일수록 중요하게 여기는 것이다. position을 정확히 기록하라.
- 페이지가 잘려서 확인할 수 없는 구간이 있으면 추측하지 말고 notes에 적어라.

[출력 형식]
상품 하나당 객체 하나씩, JSON 배열로만 출력해. 설명 문장은 붙이지 마.
각 객체는 아래 칸을 모두 가져야 해.

  - brand (문자열 또는 null)
      브랜드명. 확인 불가하면 null
  - product_name (문자열 또는 null)
      제품명. 확인 불가하면 null
  - usps (UspItem 배열)
      페이지가 내세우는 소구점 목록. 눈에 띄는 것부터 최대 12개까지. 같은 내용이 반복되면 하나로 합칠 것
  - target_audience (문자열 또는 null)
      특정 대상을 겨냥한다면 그 대상 (예: '신생아·유아', '반려동물 가정', '드럼세탁기 전용'). 명시가 없으면 null
  - has_comparison (true 또는 false)
      경쟁사·타사 제품과 비교하는 표나 그림이 있으면 true
  - certifications (문자열 배열)
      인증·수상 표기를 적힌 그대로 나열 (예: 'Dermatest Excellent', '환경표지 인증', '비건 인증'). 없으면 빈 목록
  - notes (문자열 또는 null)
      특이사항이나 사람이 재확인해야 할 부분. 페이지가 잘려 확인 불가한 구간이 있으면 여기에 적을 것. 없으면 null

  usps 배열의 각 항목은 아래 칸을 모두 가져야 해.

    - claim (문자열)
        소구점을 한 줄로 요약 (예: '8배 초고농축으로 적은 양만 사용'). 페이지의 표현을 살리되 문장으로 정리하라
    - kind (다음 중 하나: "성분·원료" / "인증·수상" / "기능·성능" / "용량·가격" / "사용편의" / "향·감성" / "안전성" / "비교·우위" / "프로모션" / "기타")
        이 소구점이 어느 유형인지. 집계를 위해 반드시 목록 중에서 고를 것
    - evidence (문자열)
        페이지에 실제로 적혀 있는 문구를 그대로 옮긴 것. 요약하거나 바꿔 쓰지 말 것. 이미지 속 글자도 그대로 옮긴다
    - emphasis (다음 중 하나: "강조" / "보통" / "약함")
        페이지에서 얼마나 크게 다루는지. 큰 글씨·전용 섹션이면 '강조', 작은 글씨나 스펙표 한 줄이면 '약함'
    - position (다음 중 하나: "상단" / "중단" / "하단")
        페이지 어느 위치에 나오는지. 위쪽일수록 판매자가 중요하게 여긴다는 뜻

  추가로 각 객체에 "file" 칸을 넣고, 위 목록 대괄호 안의 ID를 **그대로** 적어줘
  (예: "세탁세제-09"). 이 ID로 어디까지 수집했는지 추적하니, 임의로 바꾸거나
  제품명으로 대체하면 안 된다.

[주의]
- 값이 정해져 있는 칸은 반드시 그 목록 안에서 골라. 다른 말을 지어내면 안 된다.
- evidence는 페이지에 적힌 문구 그대로. 요약하지 마라.
- 확인할 수 없는 칸은 null로 두고, 왜 못 봤는지 notes에 적어라.
- 검색해서 열었을 때 상품이 여럿 나오면, 위의 '확인용' 규격과 브랜드가 맞는 것을 골라라.
- 판매가는 조사 시점(2026-09-21) 기준이라 지금은 다를 수 있다. 가격이 다르더라도
  브랜드와 규격이 맞으면 그 상품이다. 규격이 다른 옵션을 열었으면 notes에 적어라.
- 목록의 상품을 찾을 수 없으면 비슷한 걸 대신 넣지 말고, 그 번호는 건너뛰고 notes에 적어라.
