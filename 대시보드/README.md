# 제품기획 통합 대시보드 — 1단계

기획서: `문서/제품기획_대시보드_기획서.html` (8쪽)

## 무엇인가

지금까지 흩어져 있던 세 가지 — 카테고리 전수조사, USP 빈칸 찾기, 제품별 일정 역산 —
을 한 화면에서 보고 고칠 수 있게 묶은 것. 혼자 쓰는 용도라 공유·협업 기능은 없다.

게시 주소(비공개, 소유자만 열람): https://claude.ai/artifact/MD8mnzoVF5U2sdfWdpbQq7

## 구성

`index.html` 한 파일이 전부다. 스타일과 스크립트가 모두 안에 들어 있어서
따로 빌드하거나 설치할 것이 없다. 데이터만 바깥(아티팩트 db)에 둔다.

| 탭 | 하는 일 |
|---|---|
| 카테고리 조사 | 요약 타일 · 가격구간 분석(경계선 조절) · USP 매트릭스 20축×25제품 · 전수표 편집 |
| 일정 | 제품별 간트 · 주별 부하 히트맵 · 역산 계산기 |
| 설정 | 리드타임 상수 · 공정 템플릿 3종 |

## 데이터가 어디 있나

페이지 자체에는 데이터가 없다. 열릴 때 아티팩트 db에서 읽어오고,
고치면 0.5초 뒤 되써넣는다. 그래서 이 파일만 다시 올려도 내용은 그대로다.

`seed/` 는 처음 심어둔 내용의 사본이다. 되돌리거나 새로 만들 때 쓴다.

```
seed/settings/main.json                리드타임 8개 + 공정 템플릿 3종
seed/categories/kids-toothpaste.json   유아치약 25제품 · USP 20축 · 매트릭스
seed/schedules/*.json                  유아치약 / 섬유탈취제 / 고체탈취제 / 향기지속제
```

db 경로 규칙상 문서 id 는 ASCII 만 받는다. 한글 id 는 거부되므로
`kids-toothpaste` 처럼 영문 슬러그를 쓰고 한글 이름은 문서 안의 `name` 에 담았다.

## 주간 격자

`9월 2주 = 2026-09-14(월)` 을 기준점으로 삼는 월요일 시작 격자다.
팀 시트의 "N월 M주" 표기를 역산해서 맞춘 것이라, 이 기준을 바꾸면
`일정/*.tsv` 와 어긋난다. 참고로 `12월 4주 = 12/28~1/3`.
