# 크롬 확장 설치 및 사용법

파이썬도, 검은 창도 필요 없습니다. 크롬에만 넣으면 됩니다.

---

## ① 설치 (한 번만, 2분)

1. `coupang_extension` 폴더를 **바탕화면**으로 옮깁니다
   (설치 후에는 이 폴더를 지우거나 옮기면 안 됩니다. 크롬이 이 위치를 계속 참조합니다)

2. 크롬 주소창에 입력: **`chrome://extensions`**

3. 오른쪽 위 **`개발자 모드`** 스위치를 켭니다

4. 왼쪽 위 **`압축해제된 확장 프로그램을 로드합니다`** 클릭

5. 바탕화면의 **`coupang_extension` 폴더**를 선택

6. 목록에 **"쿠팡 상세페이지 이미지 수집기"** 가 나타나면 끝입니다

7. 주소창 오른쪽 **퍼즐 조각 아이콘** → 이 확장 옆의 **핀**을 눌러 고정해 두면 편합니다

> "개발자 모드"라는 이름 때문에 부담스러워 보이지만, 스토어를 거치지 않고
> 내 폴더에 있는 확장을 쓰는 것뿐입니다. 크롬이 켜져 있는 동안만 동작합니다.

---

## ② 쓰는 법

확장 아이콘을 누르면 이런 창이 뜹니다.

```
┌──────────────────────────────────────┐
│ 쿠팡 상세페이지 이미지 수집기          │
│                                      │
│ 상품 주소 (한 줄에 하나)              │
│ ┌──────────────────────────────────┐ │
│ │ 세탁세제-01 https://...          │ │
│ │ 세탁세제-02 https://...          │ │
│ └──────────────────────────────────┘ │
│ [지금 보는 탭 주소 넣기] [비우기]      │
│ 상품 사이 대기 [12] ~ [25] 초         │
│ [수집 시작] [중단] [결과 내보내기]     │
└──────────────────────────────────────┘
```

### 주소 넣는 방법 두 가지

**방법 A — 보고 있는 페이지를 넣기**
쿠팡에서 상품을 연 상태로 확장을 열고 **`지금 보는 탭 주소 넣기`** 를 누릅니다.
여러 개를 돌아다니며 계속 누르면 목록이 쌓입니다.

**방법 B — 주소를 한꺼번에 붙여넣기**
```
세탁세제-01 https://www.coupang.com/vp/products/1234567
세탁세제-02 https://www.coupang.com/vp/products/2345678
```
앞에 붙인 이름이 **폴더 이름**이 됩니다. 이름 없이 주소만 넣으면 `001`, `002`… 로 자동으로 붙습니다.

> 이름을 `세탁세제-01` 처럼 넣으면 기존 분석 자료의 항목 번호와 맞아떨어져
> 나중에 합치기가 쉽습니다.

### 시작

**`수집 시작`** 을 누르면 알아서 진행합니다. **팝업 창을 닫아도 계속됩니다.**
다시 열면 진행 상황이 보입니다.

```
진행 중 — 남은 47개
지금: 세탁세제-04
결과: 성공 3 / 차단 0 / 이미지없음 0
```

## ③ 결과 받기

다 끝나면 **`결과 내보내기`** 를 누릅니다.

내려받기 폴더에 이렇게 쌓입니다.

```
다운로드/coupang_usp/
├── 수집기록.json          ← 이 파일을 Claude 에게 보내주세요
├── 세탁세제-01/
│   ├── 001.jpg
│   ├── 002.jpg
│   └── ...
├── 세탁세제-02/
└── ...
```

`수집기록.json` 에는 항목마다 무엇이 성공하고 무엇이 실패했는지, 실패면 왜 그런지가
적혀 있습니다. 그 파일만 보내주시면 상태를 판단할 수 있습니다.

이미지까지 분석하려면 `coupang_usp` 폴더를 통째로 압축해서 보내주세요.

---

## 결과 표시 읽는 법

| 표시 | 뜻 | 할 일 |
|---|---|---|
| **성공** | 이미지를 받았습니다 | 없음 |
| **차단** | 쿠팡이 막았습니다 | 대기 시간을 늘리거나, 한참 쉬었다 재시도 |
| **이미지없음** | 페이지는 열렸는데 상세 이미지를 못 찾음 | 기록을 보내주세요. '더보기' 글자가 바뀌었을 수 있습니다 |
| **실패** | 그 외 오류 | 기록의 사유 확인 |

**연속 3회 실패하면 스스로 멈춥니다.** 막힌 채로 계속 두드리지 않기 위해서입니다.

## 안전장치

| 장치 | 내용 |
|---|---|
| 상품 사이 대기 | 기본 12~25초 무작위. **줄이지 마세요** |
| 연속 실패 중단 | 3회 |
| 차단 감지 | "비정상적인 접근", "보안 문자" 등이 보이면 저장하지 않고 기록 |
| 매 건 저장 | 브라우저를 닫아도 앞의 결과는 남습니다 |
| 이어하기 | 이미 성공한 항목은 다시 하지 않습니다 |

---

## 알아둘 것

- **이 확장은 브라우저를 속이지 않습니다.** 사장님이 평소 쓰는 크롬에서,
  화면에 있는 내용을 그대로 읽을 뿐입니다. 지문을 위조하거나 숨기는 코드는 없습니다.
- 다만 **쿠팡 이용약관은 자동 수집을 제한합니다.** 대기 시간을 넉넉히 두고,
  필요한 만큼만 쓰시는 것이 좋습니다. 판단은 사장님 몫입니다.
- **쿠팡 화면에서 실제로 동작하는지는 아직 확인되지 않았습니다.**
  개발 환경에서는 쿠팡에 접속할 수 없어(403), 쿠팡과 같은 구조의 시험용 페이지로
  '더보기 클릭 → 상세 영역 찾기 → 이미지 3장 수집'과 차단 감지까지 확인했습니다.
  실제 화면에서 '더보기' 글자가 다르면 못 찾을 수 있는데, 그때는
  `수집기록.json` 의 기록에 그 사실이 남습니다.
