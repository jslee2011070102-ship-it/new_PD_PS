# 크롬 확장 설치 및 사용법

파이썬도, 검은 창도 필요 없습니다. 크롬에만 넣으면 됩니다.

---

## ① 설치 (한 번만, 2분)

1. `coupang_extension` 폴더를 **바탕화면**으로 옮깁니다
   (설치 후에는 이 폴더를 지우거나 옮기면 안 됩니다. 크롬이 이 위치를 계속 참조합니다)

2. 크롬 주소창에 입력: **`chrome://extensions`**

3. 오른쪽 위 **`개발자 모드`** 스위치를 켭니다

4. 왼쪽 위 **`압축해제된 확장 프로그램을 로드합니다`** 클릭

5. 바탕화면의 **`coupang_extension` 폴더**를 선택

6. 목록에 **"쿠팡 상세페이지 이미지 수집기"** 가 나타나면 끝입니다

7. 주소창 오른쪽 **퍼즐 조각 아이콘** → 이 확장 옆의 **핀**을 눌러 고정해 두면 편합니다

> **사이드 패널로 열립니다.** 확장 아이콘을 누르면 브라우저 오른쪽에 패널이 붙고,
> **탭을 옮기거나 다른 곳을 눌러도 닫히지 않습니다.** 수집이 몇십 분 걸리는데
> 팝업은 클릭할 때마다 닫혀서 진행 상황을 볼 수가 없었습니다.
> 닫으려면 패널 오른쪽 위 X 를 누르면 됩니다.

> "개발자 모드"라는 이름 때문에 부담스러워 보이지만, 스토어를 거치지 않고
> 내 폴더에 있는 확장을 쓰는 것뿐입니다. 크롬이 켜져 있는 동안만 동작합니다.

---

## ①-2 새 판(버전)으로 바꿀 때

**압축파일을 다시 받아 폴더를 덮어쓰고, 크롬에서 새로고침 한 번** 이면 끝입니다.
지우고 다시 설치할 필요는 없습니다.

1. 받은 `coupang_extension.zip` 을 풀어 **바탕화면의 기존 폴더에 덮어씁니다**
   (같은 이름의 폴더에 그대로 덮어쓰기)
2. 주소창에 `chrome://extensions` 입력
3. "쿠팡 상세페이지 이미지 수집기" 칸의 **↻ (새로고침) 아이콘**을 누릅니다
4. 버전 숫자가 올라갔는지만 확인하면 됩니다

> 폴더 위치를 바꾸면 안 됩니다. 크롬이 그 위치를 계속 참조합니다.
> 위치를 옮겼다면 그때는 `압축해제된 확장 프로그램을 로드합니다` 로 다시 잡아야 합니다.
>
> **지금까지의 수집 기록은 새로고침해도 남습니다.** 이어하기도 그대로 됩니다.

## ② 쓰는 법

확장 아이콘을 누르면 오른쪽에 패널이 붙습니다.

```
┌──────────────────────────────────────────┐
│ 쿠팡 상세페이지 이미지 수집기              │
│                                          │
│ 상품 주소 (한 줄에 하나)                  │
│ ┌──────────────────────────────────────┐ │
│ │ https://www.coupang.com/vp/prod...   │ │
│ │ 세탁세제-02 | https://www.coupa...   │ │
│ └──────────────────────────────────────┘ │
│  구분자는 |  (쉼표·탭·공백도 됨)          │
│                                          │
│  ── 미리보기 ──────────────────────      │
│  확인된 상품 2개                          │
│  항목        딜번호      저장될 폴더       │
│  7891234567  7891234567  7891234567/     │
│  세탁세제-02  5550001     5550001/         │
│                                          │
│ [지금 보는 탭 주소 넣기] [비우기]          │
│ 저장 폴더 이름: [딜번호          ▼]       │
│ 상품 사이 대기 [12] ~ [25] 초             │
│ [수집 시작] [중단] [결과 내보내기]         │
└──────────────────────────────────────────┘
```

### 주소 넣는 방법

**그냥 주소만 한 줄에 하나씩 붙여넣으면 됩니다.** 이름은 안 붙여도 됩니다.

```
https://www.coupang.com/vp/products/7891234567?itemId=...&searchRank=0
https://www.coupang.com/vp/products/5550001?...
```

이름을 붙이고 싶으면 **구분자 `|`** 로 나눠 주세요. (쉼표·탭·공백도 인정합니다)

```
세탁세제-01 | https://www.coupang.com/vp/products/7891234567
세탁세제-02 | https://www.coupang.com/vp/products/5550001
```

또는 쿠팡에서 상품을 열어 둔 채 **`지금 보는 탭 주소 넣기`** 를 누르면 그 주소가 쌓입니다.

### 넣자마자 밑에 미리보기가 나옵니다 — 이걸 꼭 보세요

주소를 넣으면 **바로 아래에 표가 생깁니다.** 무엇을 수집할지, 어느 폴더에 저장될지가
시작 전에 다 보입니다.

```
확인된 상품 2개
항목          딜번호       저장될 폴더
7891234567    7891234567   7891234567/
세탁세제-02    5550001      5550001/
```

읽을 수 없는 줄은 **빨간 칸으로 따로 나옵니다.**

```
4번째 줄 — 딜번호를 찾을 수 없습니다 — 주소가 잘린 것 같습니다
           https://www.coupang.com/vp/produ
```

> **왜 이걸 넣었나.**
> 쿠팡 주소는 `?searchId=...&clickEventId=...&q=%EB%9D%BC...&searchRank=0` 처럼
> 아주 깁니다. 붙여넣다 보면 한 주소가 두 줄로 접히는 일이 생깁니다.
> 예전에는 그렇게 **잘린 주소도 조용히 목록에 들어가** 엉뚱한 페이지를 긁고도
> "성공"으로 끝났습니다. 두 개를 넣었는데 하나만 제대로 된 게 그 때문입니다.
> 이제는 딜번호(`/vp/products/숫자`)가 없는 주소는 **받지 않고 빨간 칸으로 보여줍니다.**

> **꼬리표는 자동으로 떼어냅니다.**
> `searchId`, `clickEventId`, `searchRank` 같은 것은 "어느 검색에서 눌렀나"를
> 기록하는 것일 뿐 상품과 무관합니다. 그래서 떼어냅니다. 옵션을 가리키는
> `itemId`, `vendorItemId` 는 남깁니다. 덤으로, 같은 상품을 다른 검색에서 두 번
> 넣어도 **같은 주소로 모여 중복이 저절로 사라집니다.**

### 저장 폴더 이름 — 세 가지 중에 고릅니다

| 고르는 값 | 폴더 이름 예 | 언제 |
|---|---|---|
| **딜번호** (기본) | `7891234567/` | 그냥 이걸 쓰세요 |
| 딜번호 + 제품명 | `7891234567_리큅 세탁세제 10L 말통/` | 폴더만 보고 어느 제품인지 알고 싶을 때 |
| 내가 붙인 이름 | `세탁세제-01/` | `이름 \| 주소` 로 넣어 기존 분석 번호와 맞출 때 |

**딜번호를 기본으로 둔 이유.** 예전에는 `001`, `002`… 로 붙였습니다. 그런데 이건
**그날 목록의 순서**일 뿐입니다. 다음에 목록 순서를 바꿔 돌리면 어제의 `001` 폴더에
오늘의 다른 제품이 덮어써집니다. 딜번호는 상품마다 하나뿐이어서 이런 일이 없습니다.
같은 상품을 다시 돌리면 **늘 같은 폴더에 깨끗하게 덮어씁니다.**

> **덮어쓸 때 예전 파일은 지웁니다.** 지난번에 9장을 받았고 이번에 2장만 받으면
> `003~009` 가 남아 폴더만 보고는 몇 장인지 알 수 없습니다. 그래서 그 폴더의
> `001.jpg` 꼴 파일만 먼저 지우고 새로 저장합니다. 다른 파일은 건드리지 않습니다.

### 두 가지 선택

**☐ 이미지를 내려받지 않고 주소만 모으기** ← **먼저 이걸로 해보세요**

이미지를 저장하지 않고 **주소만** 모읍니다. 훨씬 빠르고 디스크를 쓰지 않습니다.

**실제로 확인됐습니다.** 수집한 주소로 이미지를 받아올 수 있습니다(2026-09-28 검증).
그래서 이미지 파일을 따로 보내실 필요가 없습니다. `수집기록.json` 하나면 됩니다.

수집이 잘 되는지 확인된 뒤에, 필요하면 체크를 풀고 이미지까지 받으면 됩니다.

**☑ 실패하면 모바일 주소로 한 번 더 시도** (기본 켜짐)

PC 주소에서 막히거나 이미지를 못 찾으면 `m.coupang.com` 주소로 다시 시도합니다.
모바일 화면은 구조가 단순해 이미지가 더 잘 잡히는 경우가 있습니다.
어느 쪽으로 성공했는지는 기록의 `usedUrl` 에 남습니다.

### 시작

**`수집 시작`** 을 누르면 알아서 진행합니다. **팝업 창을 닫아도 계속됩니다.**
다시 열면 진행 상황이 보입니다.

```
진행 중 — 남은 47개
지금: 세탁세제-04
결과: 성공 3 / 차단 0 / 이미지없음 0
```

## ③ 결과 받기

다 끝나면 **`결과 내보내기`** 를 누릅니다.

내려받기 폴더에 이렇게 쌓입니다.

```
다운로드/coupang_usp/
├── 수집기록.json          ← 이 파일을 Claude 에게 보내주세요
├── 7891234567/            ← 폴더 이름이 딜번호입니다
│   ├── 001.jpg
│   ├── 002.jpg
│   └── ...
├── 5550001/
└── ...
```

`수집기록.json` 에는 항목마다 아래가 들어 있습니다.

| 칸 | 뜻 |
|---|---|
| `status` | 성공 / 차단 / 이미지없음 / 실패 |
| `productId` | 딜번호 (주소에서 뽑은 상품번호) |
| `folder` | 이미지가 실제로 저장된 폴더 이름 |
| `usedUrl` | 실제로 성공한 주소 (PC인지 모바일인지) |
| `imageUrls` | 수집한 **상세 이미지** 주소 (썸네일 아님) |
| `scope` | 어디서 긁었는지 (`#productDetail` 등) |
| `fallback` | true 면 상세 영역을 못 찾아 페이지 전체를 훑었다는 뜻 |
| `log` | 무엇을 했고 어디서 막혔는지 |

**먼저 `수집기록.json` 하나만 보내주세요.** 확장이 제대로 도는지, 상세 이미지를
몇 장 잡았는지가 그 파일로 판단됩니다. 그 주소로 이미지를 받아올 수 있는지도
제가 확인해 보겠습니다. 안 되면 그때 이미지까지 받으시면 됩니다.

이미지까지 직접 받으셨다면 `coupang_usp` 폴더를 통째로 압축해 보내주셔도 됩니다.

## 결과 표시 읽는 법

| 표시 | 뜻 | 할 일 |
|---|---|---|
| **성공** | 이미지를 받았습니다 | 없음 |
| **차단** | 쿠팡이 막았습니다 | 대기 시간을 늘리거나, 한참 쉬었다 재시도 |
| **이미지없음** | 페이지는 열렸는데 상세 이미지를 못 찾음 | 기록을 보내주세요. '더보기' 글자가 바뀌었을 수 있습니다 |
| **실패** | 그 외 오류 | 기록의 사유 확인 |

**연속 3회 실패하면 스스로 멈춥니다.** 막힌 채로 계속 두드리지 않기 위해서입니다.

## 안전장치

| 장치 | 내용 |
|---|---|
| 상품 사이 대기 | 기본 12~25초 무작위. **줄이지 마세요** |
| 연속 실패 중단 | 3회 |
| 차단 감지 | "비정상적인 접근", "보안 문자" 등이 보이면 저장하지 않고 기록 |
| 매 건 저장 | 브라우저를 닫아도 앞의 결과는 남습니다 |
| 이어하기 | 이미 성공한 항목은 다시 하지 않습니다 |
| 잘린 주소 거부 | 딜번호가 없는 주소는 받지 않고 빨간 칸으로 알려 줍니다 |
| 중복 제거 | 같은 딜번호를 두 번 넣으면 한 번만 합니다 |

## 알아둘 것

- **이 확장은 브라우저를 속이지 않습니다.** 사장님이 평소 쓰는 크롬에서,
  화면에 있는 내용을 그대로 읽을 뿐입니다. 지문을 위조하거나 숨기는 코드는 없습니다.
- 다만 **쿠팡 이용약관은 자동 수집을 제한합니다.** 대기 시간을 넉넉히 두고,
  필요한 만큼만 쓰시는 것이 좋습니다. 판단은 사장님 몫입니다.
- **쿠팡 화면에서 동작하는 것은 확인됐습니다.** '더보기' 클릭, 상세 영역 찾기,
  이미지 수집까지 실제 상품 페이지에서 돌았습니다.
- 다만 쿠팡이 화면 구조를 바꾸면 못 찾을 수 있습니다. 그런 경우
  `수집기록.json` 의 `log` 에 "무엇을 했고 어디서 막혔는지"가 남습니다.
  그 파일을 보내주시면 고칠 수 있습니다.
- **이미지 장수가 유난히 적으면(1~2장) 알려 주세요.** 상세페이지가 원래 짧은 것일
  수도 있고, 구조가 달라 일부만 잡힌 것일 수도 있습니다. 기록을 보면 구분됩니다.
