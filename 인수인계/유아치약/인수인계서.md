## 2. 제품 구조 — 이게 가장 중요한 제약

**제품 제안은 반드시 두 라인으로 낸다. 가성비 라인과 프리미엄 라인.** 이 계정의 모든 제품기획에 적용되는 원칙이고, 한 라인만 제안한 기획서는 반려된다.

그리고 **두 라인의 차별화 축은 서로 다른 주제여야 한다.** 같은 축을 가성비에서 쓰고 프리미엄에서 또 쓰면 프리미엄이 값을 받을 근거가 사라진다. 실제로 1차 안이 이 이유로 전면 폐기됐다(§6).

현재 확정된 두 축:

| | 라인 A (가성비) | 라인 B (프리미엄) |
|---|---|---|
| 축 | **1회 사용량** — 짜기 전 | **헹굼 + 연마도** — 닦는 동안과 닦은 뒤 |
| 형태 | 튜브 110~120g × 4개입 | 튜브 60g × 2개 (총 120g) |
| 판가 | 9,800~10,500원 / 10g당 210~240원 | 12,000~14,000원 / 10g당 1,000~1,170원 |
| 차별화 | 좁은 노즐 + 1회분 가이드 인쇄 / 중금속·보존제 성적서 원본 | 저연마(배합비 숫자 공개) / 저발포 / 용기까지 시험 |
| 불소 | 1,000ppm SKU와 1,450ppm SKU를 **따로** | 1,450ppm (유아용 1,000ppm) |

두 축 모두 **25개 중 다룬 제품이 0개**다. 이게 이 기획의 근거 전부다.

## 3. 소구 구조 — 1위가 쓰는 문법

프리미엄 라인은 1위 브랜드가 쓰는 구조를 그대로 빌려 썼다.

```
공포(당연히 없어야 할 것의 위험)  →  규제 공백(그런데 기준이 없다)  →  자체 기준 공개(그래서 우리는)
```

1위는 **중금속**으로 이 구조를 돌려 10g당 1,180원을 받는다. 우리는 같은 구조를 **연마도**로 돌린다.

| 1위 | 라인 B |
|---|---|
| 미국 치약 90% 중금속 검출 / 영유아 흡수율 성인 4~5배 | 유치 법랑질은 영구치의 절반 두께(1.14mm 대 2.58mm) |
| 치약 완제품에 중금속 관리기준 없음 | ISO 11609 RDA 250은 **어른 기준 하나뿐**, 국내 치약제 기준에는 연마도 항목 자체가 없음 |
| 자체 기준 납 1ppm 이하 공개 | 연마제 배합비를 숫자로 공개 |
| "들어 있지 않다"를 증명 | "덜 깎는다·덜 씻긴다"를 증명 |

핵심은 **당연한 것을 당연하지 않게 포장하는 것**이다. 숫자로 경쟁하지 않고 다른 질문을 던진다.

### 반드시 같이 적어야 할 것

연마도 소구에는 업계 반론이 있다 — "RDA 250 이하면 모두 안전하다". 기획서는 이 반론을 **본문에 그대로 적어 두었다.** 빼지 말 것. 빼면 주장이 과장이 되고, 표시·광고 심사에서 걸린다.

## 5. 근거로 쓴 사실 — 출처까지 확인된 것만

새로 수치를 만들지 말 것. 아래는 전부 1차 또는 준1차 확인을 마친 것이다.

### 규제

- 「의약외품에 관한 기준 및 시험방법」 고시 제2024-73호 전문 587쪽(594,892자)을 받아 검색한 결과 **"치약"·"세치제"·"Dentifrice"가 단 한 번도 나오지 않는다.** 중금속 한도는 원료·첨가제에만 붙는다. 따라서 1위의 "치약 완제품에는 중금속 관리기준이 없다"는 **사실이다.** 정확히는 "일률적 수치 기준이 없고 제조사가 자체 기준을 세워 신고한다".
- 「의약외품의 표준제조기준」 **제1장 치약제**에서 직접 확인한 것 세 가지 — ① 법정 주의사항 (2)항이 *"사용 후에는 입안을 충분히 헹구어 낼 것"* ② 불소 **총량 1,000ppm** 상한 ③ 연마제 배합한도는 있으나 **RDA·연마도 기준은 아예 없음.**
- 그러므로 **1,450ppm은 표준제조기준 밖이라 별도 품목허가가 필요하다**(신고가 아님). 1,000ppm은 신고로 간다. 두 SKU의 허가 경로가 다르다는 것이 일정의 핵심 변수다.

### 사용량 (라인 A)

- BDJ Open 2024;10:7 — 부모 61명에게 "쌀알만큼" 짜 달라고 했을 때 실측 0.263g / 0.281g. 정량은 0.045g / 0.039g. **5.9~7.2배 초과.**
- ADA·JADA 2014 / CDC — 3~6세의 38.4%가 완두콩보다 많이 쓴다.

### 연마도 (라인 B)

- 유치 법랑질 1.14mm 대 영구치 2.58mm (PubMed 19937744). 법랑질에는 살아 있는 세포가 없어 **깎이면 재생되지 않는다.**
- ISO 11609 — RDA 상한 250. **어린이 전용 한도는 없다.**
- 연세대 in situ 연구 — RDA 100은 6.60μm, RDA 30은 4.23μm를 깎아낸다.

### 헹굼 (라인 B)

- 영국 NHS — "양치 직후 헹구지 말라. 남은 불소가 씻겨 희석되어 예방 효과가 떨어진다." 모든 연령에 1,350~1,500ppm 허용, 낮춰도 **최소 1,000ppm**.
- SDCEP 소아 우식예방 지침 / BDJ 2014.
- 즉 국내 법정 문구(충분히 헹구라)와 선진국 권고가 **정반대**다. 그 사이를 설명한 제품이 25개 중 0개다.

### 시장

- TOP25 월 매출 추산 14.9억원(연 환산 178억). **쿠팡 TOP25 한정 추산치이고 카테고리 전체가 아니다.** 반드시 이 단서를 붙여야 한다.
- 매출 추산 = 판가 × 월구매자수 × 2. 구매자수 표기가 하한값("1만명 이상")이라 실제는 이보다 많을 수 있다.
- 국내 어린이치약 공식 시장 규모는 **찾지 못했다.** 검색된 2020~2021년 자료는 같은 문서 안에서도 수치가 맞지 않아 인용하지 않았다. 필요하면 식약처 의약외품 생산실적을 별도로 확인할 것.
- 브랜드 13개가 25자리를 나눠 갖고, 국내 최대 구강 브랜드가 SKU 4개로도 14.3%에 그친다. **지배 사업자가 없다.**

## 6. 이미 폐기된 안 — 다시 꺼내지 말 것

세 건 모두 사용자가 직접 지적해서 뒤집힌 것이다. 같은 실수를 반복하면 신뢰를 잃는다.

### ① 프리미엄 축을 "토출량 시험"으로 잡은 안 — 폐기

튜브에서 나오는 양은 **사람이 얼마나 세게, 얼마나 오래 짜느냐로 결정된다.** 노즐이 고정하는 것은 띠의 **굵기**이지 길이가 아니다. 그래서 토출량 시험을 받아도 "1회 0.25g"을 보증할 수 없다. 성적서를 한 장 더 주는 것으로 프리미엄 값을 받겠다는 발상도 너무 약하다는 지적이 있었다.

### ② 4개입 안에 1,000ppm과 1,450ppm을 섞어 넣는 안 — 폐기

당장 쓰지 못하는 제품이 절반이 되므로 구매 저해 요인이다. 전수 확인 결과 **25개 중 한 묶음에 다른 농도를 섞어 파는 사례가 0개**였다. 단계를 나눈 제품은 전부 별도 SKU로 판다. 농도별로 SKU를 쪼개는 쪽이 맞다.

### ③ 조르단 18위 "리필"을 참고 사례로 든 것 — 반면교사로 전환

상세 이미지 10장을 다시 받아 확인한 결과, **리필은 파우치가 아니라 펌프 헤드만 없는 똑같은 플라스틱 통**이었다. 본품을 하나 더 주고 헤드를 옮겨 끼우는 구성을 "지속 가능한 환경을 위한 선택"으로 포장한 것이다. 따라 할 아이디어가 아니다.

## 8. 일정 제약

목표는 **12월 4주 출시**, 본품 입고 2026-12-30이다. 공정 순서는 아래가 전부다.

```
제품기획 → 제형샘플 1·2·3차 + 샘플링 관능테스트 → 제형 확정
         → 파생신고(3주) ─┐
         → 패키지 디자인 시안(3주) ─┴→ 디자인 데이터 전달 → 부자재 제작·입고(5주) → 양산(2주) → 본품 입고(1주)
```

- 신규 품목허가가 아니라 **제조사가 보유한 대표신고에서 파생신고**로 간다. 해당 제조사와는 고불소 치약을 함께 진행한 이력이 있다.
- 디자인 방향은 제품기획 직후부터 잡되, **후면 표기문구 때문에 파생신고 시작과 동시에 가안으로 인쇄를 넣는다.** 이 겹치기가 일정의 핵심이다.
- 부자재는 사급이 아니지만 **디자인은 내부에서 만들어 데이터를 제조사로 넘긴다.**
- 리드타임 상수 : 파생신고 3주 / 패키지 디자인 시안 3주 / 부자재 발주~입고 5주 / 제품 촬영 2주 / 양산 2주 / 본품 입고 1주. **제형 확정 → 본품 입고 = 8주.**
- 주차 격자는 **월요일 시작**이고 `9월 2주 = 2026-09-14`가 기준점이다. 이 기준으로 **12월 4주 = 12/28~1/3**이다. 팀 시트 표기를 역산해 맞춘 것이므로 바꾸면 TSV와 어긋난다.
- "시험생산·품질 승인" 같은 항목은 쓰지 않는다. 실제로는 **샘플링 관능테스트 2~3회차**다.

## 9. 지켜야 할 원칙

| 원칙 | 이유 |
|---|---|
| **상품 URL을 지어내지 않는다** | 확인되지 않은 링크는 공란으로 둔다. 과거에 이 선을 지켰기 때문에 25건 URL이 전부 검증본이다 |
| **문서에 회사명을 적지 않는다** | 기입 요청이 있을 때만 적는다. 상대 회사(경쟁사·제조사)는 예외 |
| **쿠팡 수집 페이싱을 낮추지 않는다** | 제품 간 12~25초, 연속 3회 실패 시 중단. 이 값을 줄이면 안 된다 |
| **브라우저 지문 위조·봇 탐지 우회는 만들지 않는다** | |
| **수치는 출처가 있는 것만** | 찾지 못한 것은 "확인 못 한 것"으로 명시한다. 기획서 2쪽이 그 예다 |

## 10. 작업 방식

- 기획서는 **HTML이 원본**이고 PDF는 `문서생성/기획서_PDF생성.py`로 뽑는다 (Playwright가 `http.server`로 띄운 페이지를 print-to-PDF).
- 폰트는 `문서생성/폰트_심기.py`가 Pretendard를 **실제 쓰인 글자만 골라 심는다.** 본문을 고치면 글자 집합이 바뀌므로 **반드시 다시 돌려야 한다.** 안 돌리면 새로 들어간 글자가 깨진다. 스크립트는 기존 `@font-face`를 먼저 걷어내므로 여러 번 돌려도 안전하다.
- **쪽수는 PDF를 직접 세어 확인한다.** 브라우저가 재는 높이는 믿을 수 없다.
- 수정 요청은 PDF에 주석을 달아 돌아온다. 주석 본문만으로는 어디를 가리키는지 모르므로, `pymupdf`의 `page.annots()` → `a.vertices` → `get_text(clip=...)`로 **주석이 덮은 문장을 함께 뽑아 읽는다.**
- 작업 브랜치는 `claude/sharp-ramanujan-l7g9c5`. 다른 브랜치에 푸시하지 않는다.
